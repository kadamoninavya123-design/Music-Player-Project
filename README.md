# 🎵 Music Player Project

A simple web-based music player built with HTML, CSS, and JavaScript. Play, pause, and switch between songs directly in the browser.

## Features
- Play / pause songs
- Switch between multiple tracks
- Clean, browser-based interface (no installation needed)

## Tech Stack
- HTML
- CSS
- JavaScript

## Live Demo
🔗 [Try it here](https://kadamoninavya123-design.github.io/Music-Player-Project/music.html)

## How to Run Locally
1. Clone this repository
2. Open `music.html` in a browser (or use VS Code's Live Server extension for best results)
3. Click a song to play it
